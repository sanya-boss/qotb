# Заявки с сайта: Google-таблица + письмо на почту

Когда участница нажимает **Submit** в форме «Become the Queen of the Baltic!» на qotb.eu, происходит следующее:

1. Её фото сохраняются в [папку на Google Drive](https://drive.google.com/drive/folders/1i2a6hXyHNusEXC44IT87D5J-rRKB5ySL). Для каждой участницы создаётся своя подпапка с её именем, например «Anna Ivanova — 27.11.2026 (№ 5)».
2. На лист **Заявки** добавляется заявка в виде **вертикальной карточки**. В левой колонке названия полей, в правой ответы: статус, дата, имя, почта, телефон, страна, Instagram, текст о себе, **фото прямо в ячейках** (одно под другим), ссылка на папку с фото и место для заметок. **Новые заявки появляются сверху.** Длинный текст переносится на новые строки, и строка растягивается по высоте. Почта и Instagram кликабельны.
3. На **lumierefoundation01@gmail.com** приходит письмо «Queen of the Baltic — новая заявка: Имя». В письме все данные заявки, фото во вложении и кнопки «Открыть в таблице» и «Открыть фото». Если нажать «Ответить», ответ уйдёт прямо участнице.

Запросы от партнёров (форма «Let’s reign together.», когда её кнопка снова будет включена) попадают на отдельный лист **Партнёры**.

В каждой карточке есть строка **Статус** с выпадающим списком: Новая / На рассмотрении / Связались / Принята / Отклонена. У каждого статуса свой цвет. Строка **Заметки** для ваших заметок.

Готовая таблица в формате Excel: **File → Download → Microsoft Excel (.xlsx)**. Фото сохранятся в ячейках.

Файл `tools/applications/Queen of the Baltic — Applications.xlsx` — образец того, как выглядит таблица: такая же карточка-пример.

## Настройка (один раз, ~10 минут)

Удобнее всего всё делать в аккаунте **lumierefoundation01@gmail.com**. Если делаете в другом Google-аккаунте, у него должен быть доступ на редактирование к папке для фото. Письма в любом случае уйдут на lumierefoundation01@gmail.com, потому что этот адрес уже вписан в скрипт.

### 1. Создать таблицу
Откройте https://sheets.new и назовите таблицу, например «Queen of the Baltic — заявки».

### 2. Вставить скрипт
1. В таблице: **Extensions (Расширения) → Apps Script**.
2. Удалите всё, что там написано, и вставьте целиком содержимое файла `tools/applications/Code.gs`.
3. Почта для уведомлений уже вписана: `const NOTIFY_EMAIL = 'lumierefoundation01@gmail.com';`. Папка для фото тоже: `PHOTOS_FOLDER_ID`. Менять их нужно только если захотите другие.
4. Нажмите 💾 (Save).

### 3. Подготовить таблицу
1. Вверху в списке функций выберите **setup** и нажмите **Run**.
2. Google попросит разрешения: **Review permissions** → выберите аккаунт → **Advanced** → **Go to … (unsafe)** → **Allow**. Это ваш собственный скрипт, ему нужен доступ к таблице, Google Drive и отправке почты.
3. В таблице появятся листы **Заявки** и **Партнёры** с оформлением.

### 4. Проверить
Выберите функцию **testSubmission** → **Run**. В таблице должна появиться тестовая карточка, а на почту прийти письмо. Тестовую карточку потом удалите (выделите её строки → правой кнопкой → Delete rows).

### 5. Опубликовать
1. **Deploy → New deployment**.
2. ⚙️ рядом с «Select type» → **Web app**.
3. **Execute as: Me**, **Who has access: Anyone**. Это нужно, чтобы форма на сайте могла отправлять заявки. Таблицу при этом никто, кроме вас, не видит.
4. **Deploy** → скопируйте **Web app URL**. Он заканчивается на `/exec`.

### 6. Подключить к сайту
Пришлите этот URL Claude. Либо вставьте его сами в `site/index.html` в строку
`const APPLY_ENDPOINT = '';` → `const APPLY_ENDPOINT = 'https://script.google.com/macros/s/…/exec';`

Пока URL не вставлен, форма показывает: «The form is not connected yet. Please write to contest@qotb.eu.»

### 7. Капча «Я не робот» (Google reCAPTCHA)
1. Откройте https://www.google.com/recaptcha/admin/create (под тем же Google-аккаунтом).
2. **Label:** Queen of the Baltic. **reCAPTCHA type:** Challenge (v2) → **«I'm not a robot» Checkbox**.
3. **Domains:** `qotb.eu`, `www.qotb.eu`, `sanya-boss.github.io`. → **Submit**.
4. Google покажет два ключа:
   - **Site key** (ключ сайта) — уже вставлен в сайт (`RECAPTCHA_SITE_KEY`). Это публичный ключ, его можно показывать.
   - **Secret key** (секретный ключ) — **никому не присылайте**. В Apps Script: ⚙️ **Project Settings → Script properties → Add script property**: имя `RECAPTCHA_SECRET`, значение — секретный ключ → **Save**.

После этого заявку нельзя отправить без галочки «I'm not a robot», а сервер дополнительно проверяет каждую заявку у Google. Пока ключи не добавлены, форма работает без капчи.

## Полезно знать
- **Изменили скрипт?** Чтобы изменения заработали на сайте: **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**. URL при этом не меняется.
- **Лимит писем:** обычный Gmail отправляет до 100 уведомлений в день, Google Workspace — до 1500.
- Фото уменьшаются прямо в браузере участницы: до 1600 px на Drive и в письме, до 600 px в ячейке таблицы. Поэтому форма отправляется быстро даже с телефона.
- Защита от спама: капча «I'm not a robot» (после шага 7) и скрытое поле-ловушка для ботов.
